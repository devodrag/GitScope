Built local-first.

Every GitHub dashboard shows you today and forgets yesterday. GitScope keeps a daily snapshot of everything you follow — the history accumulates on your disk and belongs to you.

📍

Snapshots you own

Daily stars, forks, watchers and issues for every followed repository, written into local SQLite. Growth charts for any period, even months later.

🔌

Works offline

ETag-backed response cache is replayed when GitHub is unreachable. Browse and analyze without network; everything syncs back later.

🔔

Release notifications

A personal watchlist with native desktop notifications the moment followed projects publish new releases.

⚖️

Side-by-side compare

Put any two repositories next to each other: stars, issues, languages, activity and release history.

⌨️

Keyboard-first

Ctrl+K command palette, dark and light themes, English and Russian interface.

🪶

Native and light

Tauri 2 with a Rust backend — a 6 MB deb instead of a browser tab farm, politely respecting GitHub rate limits.

See it in 30 seconds.

Install in one minute.

Pick your poison. Updates arrive with a regular apt upgrade.

Debian, Ubuntu, Mint — apt repository

curl -fsSL https://gitscope.dev-is.fun/apt/gitscope-archive-keyring.asc | sudo gpg --dearmor -o /usr/share/keyrings/gitscope-archive-keyring.gpg
echo "deb [signed-by=/usr/share/keyrings/gitscope-archive-keyring.gpg] https://gitscope.dev-is.fun/apt stable main" | sudo tee /etc/apt/sources.list.d/gitscope.list
sudo apt update
sudo apt install git-scope
